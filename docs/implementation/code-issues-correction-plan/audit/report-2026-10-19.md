Un cuerpo con `data` o `meta` ausentes no se convierte aquí en un error de respuesta, aunque el método promete un objeto utilizable.

- **A05 · Baja · La paginación de categorías retiene y reconstruye todos los resultados recursivamente (55–59).** Cada tanda espera a todas las restantes y luego vuelve a copiar su resultado acumulado.
